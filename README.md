# Integrated-MD-ML-Framework-for-Predicting-Fracture-Mechanics-in-Defective-Graphene.
This project examines how void defects weaken graphene. We ran 1000 molecular dynamics simulations using LAMMPS to test defective sheets under tension. To save time, we built a Random Forest model that predicts the breaking point, proving that pulling speed drives 64% of the material's failure
